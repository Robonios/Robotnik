# Definitive Index Membership Audit — full universe vs. the frontier bar

**The bar (standing rule).** A constituent stays IN only if its **core business is
the physical frontier-stack value chain** — semiconductors, robotics/automation,
space, frontier materials — including direct supply chain, **frontier-specific
software (EDA stays; general AI/data/enterprise software is out)**, and
**operators + integrators of frontier hardware (in)**. OUT = diversified-industrial
/ diversified-defense / Big-Tech / general-software / energy / autos where frontier
is *incidental*, not core.

**Method.** Existing sector tags are stale/auto-assigned and were NOT trusted;
each name re-derived from actual core business. Clear calls auto-decided;
**contested flagged for founder review**; high-weight names (≥0.4%) given a second
(verifier) pass. Three dispositions: **IN / OUT / CONTESTED** (+ **READMIT** =
currently flagged-excluded but actually frontier → a data/curation error, not a
business exclusion).

**Counts:** 305 public equities. Proposed: **~198 IN, ~58 OUT, ~41 CONTESTED, ~8 READMIT** (pre-review).
**Weight removed if all OUT confirmed: ≈22–28%** depending on the contested clusters.

for the frontier stack), NOT horizontal suppliers serving all electronics/industries.

dominated by non-frontier revenue is OUT of the index even if it makes a critical
frontier input — that input stays tracked in the bottleneck/commodities layer with
the company NAMED as supplier.
