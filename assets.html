This is the Robotnik public-equity universe, set out by classification rather than by size. Every entity is placed by sector, by its tier in the value chain, and by a bottleneck rating that records how hard its position is to route around, from critical down to low. The list is a way to read the frontier by chokepoint: a small supplier sitting on a control point appears next to the largest names, because the lens is dependence, not scale.

Filter by any combination of sector, value-chain tier and bottleneck rating; the useful query is the cross-cut. Seven entities carry a full nine-layer profile, marked View → in the profile column. The list is classification only: no market data of any kind appears here, nor in any file this page emits.
